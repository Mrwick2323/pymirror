# pymirror
mostly vibecoded website mirroring slop

usage:
```python3 pymirror.py -d https://domain.you/want/to/mirror/ -f ./folder/to/put/directory(s)/in```

>wait until it says hosting at ./folder/to/put/directory(s)/in/and/then/some/more/stuff/probably on port 8000 (or other specified port) and then go to [here](http://localhost:8000) (localhost:8000) and just click around on the website/webapp, you'll only download functionality for files that are called/downloaded, so if its a website you gotta move around a lot usually, but for like a browser game just playing the game for a bit should be good enough.

>example usage:
>`python3 pymirror.py -d https://html-classic.itch.zone/html/18047452/Production%20WebGL/index.html -f ./super-auto-pets`
>and then just play the game, sign in, start a match, and just try and load all the images.
